# Кейс 1: Сорняки на фотографиях с дрона

## Установка
```bash
pip install -r requirements.txt
```
(если нет GPU — всё равно заработает на CPU, просто немного медленнее)

## Запуск
```bash
python weed_detector.py \
    --ref_dir /data/Сорняки \
    --field_dir /data/ФотоПолей \
    --out_dir ./results
```

## Что получите на выходе (в `./results`)
- `results.csv` / `results.json` — построчно каждая найденная "точка сорняка":
  фото, id, вид, уверенность классификации, стадия вегетации, координаты bbox.
- `summary_by_species.csv` — агрегированный подсчёт: сколько сорняков каждого вида найдено суммарно.
- `annotated/` — те же фото полей с нарисованными боксами и подписями (вид + стадия).

## Как это работает
1. **Детекция** (`detect_plant_regions`) — по HSV-маске зелёного цвета находит
   отдельные растения на фото поля через контуры OpenCV. Быстро, без обучения.
2. **Классификация вида** (`ClipClassifier` + `build_reference_embeddings`) —
   каждое эталонное фото из `/data/Сорняки/<Вид>/` кодируется предобученной
   моделью CLIP в вектор-эмбеддинг, эмбеддинги усредняются по виду. Каждый
   найденный на поле объект тоже кодируется и сравнивается по косинусному
   сходству с эталонами вида — какой ближе, тот и присваивается.
   Порог `SIMILARITY_THRESHOLD` отсекает случаи "непохоже ни на что" → `unknown`.
3. **Стадия вегетации** (`estimate_stage`) — сейчас это простая эвристика по
   размеру кропа и доле светлых/цветных пятен (признак цветения). Если в
   эталонах стадии размечены отдельными подпапками — стоит заменить эту
   функцию на такой же similarity-подход, как для вида (это даст точность
   выше, чем эвристика).

## Что можно быстро подкрутить под ваши данные
- `MIN_CONTOUR_AREA` — если много мелкого шума детектируется как сорняк, увеличьте.
- Диапазон `lower_green` / `upper_green` — если освещение/оттенок поля отличается.
- `SIMILARITY_THRESHOLD` — если слишком много `unknown`, снизьте (например до 0.45–0.5);
  если путает похожие виды — повысьте.

## Если детекция по цвету работает плохо (перекрытия, похожий цвет культуры и сорняка)
Замена на более сильный, но всё ещё готовый инструмент без обучения:
- **SAM (Segment Anything)** — сегментирует все объекты на фото, затем те же
  сегменты прогоняются через CLIP-классификацию как сейчас.
Логика классификации/стадии/экспорта останется без изменений — меняется
только функция `detect_plant_regions`.
