# Кейс 1: Сорняки на фотографиях с дрона

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python weed_detector.py --ref_dir /data/Сорняки --field_dir /data/ФотоПолей --out_dir ./results --photo_area_m2 12.5
```

`--photo_area_m2` — реальная площадь земли, которую покрывает ОДНО фото
(нужна, чтобы перевести количество сорняков в шт/м² для решения по
опрыскиванию). Если не знаете точно — не указывайте: скрипт всё равно
отработает, просто в decision_report.csv будет "н/д" вместо решения.

Быстрая отладка детекции (без CLIP, за секунды):
```bash
python weed_detector.py --field_dir /data/ФотоПолей --out_dir ./results --debug_mask
```

## Пайплайн 
**ШАГ 1** — находим ВСЕ растения на фото (детекция по цвету) и убираем из
рассмотрения культуру (пшеницу и т.п.) — сравнение эмбеддингов с эталонами,
похожие на культуру объекты дальше не идут.

**ШАГ 2** — среди оставшихся (кандидатов в сорняки) определяем вид, класс/
подкласс и фазу развития, формируем агрономическую рекомендацию.

## Что получите на выходе (в `./results`)
- `results.csv` / `results.json` — каждая находка: вид, класс (Двудольные/
  Злаковые), подкласс (малолетние/многолетние), стадия, нормализованная фаза,
  рекомендация по дозировке, координаты.
- `summary_by_species.csv` — подсчет по видам/классам/подклассам.
- `decision_report.csv` — **по каждому фото**: количество малолетних,
  многолетних, их плотность (шт/м², если указана площадь) и итоговое решение
  (не опрыскивать / стандартная норма / максимум / срочно обработать).
- `annotated/` — фото с боксами (красный = сорняк, оранжевый = неопознан,
  тонкий зеленый = культура, отфильтрована).

## Структура эталонов
```
/data/Сорняки/
    Осот/
        img1.jpg
    Пырей/
        всходы/
            img1.jpg
        розетка/
            img1.jpg
        цветение/
            img1.jpg
    Пшеница/               <- культура, слово "пшениц" -> автоматически фильтруется
        img1.jpg
```

## Параметры для подстройки (в начале файла)
- `MIN_CONTOUR_AREA`, `MERGE_KERNEL_SIZE` — детекция (см. `--debug_mask`).
- `SIMILARITY_THRESHOLD` — порог уверенности классификации вида.
- `CROP_KEYWORDS` — слова-маркеры "это культура, не сорняк".
- `WEED_TAXONOMY` — сопоставление вид → класс/подкласс.
- `PHASE_KEYWORDS` — сопоставление метки стадии → фаза шпаргалки.
